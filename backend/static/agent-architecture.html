Bureau pattern: All 7 agents (coordinator + 5 specialists + benchmark) run in a single python agents/bureau.py process behind port 8010. Each agent retains its own stable agent1q… address derived from its seed — copy these into .env once. The FastAPI server is a separate process on port 8000.
🌐
Fetch.ai Almanac: Each uAgent auto-registers on the Almanac on startup (testnet — no manual key needed). send_sync_message() resolves an agent1q… address through the Almanac, enabling decentralised agent discovery. The coordinator locates specialists via env-configured addresses (stable via seed).
